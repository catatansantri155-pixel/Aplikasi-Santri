# Aplikasi Monitoring Santri — Ponpes Minhajus Sunnah Magelang

Aplikasi mobile-first untuk monitoring belajar santri Marhalah Wustha: kehadiran, hifzh (Buku Hafalan), diniyyah, olahraga, dan catatan musyrif. Orang tua hanya dapat melihat data anaknya sendiri (ditegakkan RLS Supabase).

- `apps/web` — Next.js (deploy Cloudflare Pages)
- `supabase/migrations` — skema, fungsi nilai, view rekap/grafik, RLS
- `docs/TAHAPAN.md` — tahapan implementasi paralel & bertahap
- `docs/ARSITEKTUR.md` — peran, aturan bisnis, alur data
